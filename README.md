# AtmosPlayer

AtmosPlayer 是一个面向本地杜比全景声（Dolby Atmos）音乐收藏的 Android 播放器。

## 简介

这是一个 Android 本地音乐播放器项目，重点面向本地杜比全景声音乐收藏，强调沉浸式播放体验、歌词体验与音频信息展示。

## 功能

- 本地音乐播放
- Dolby Atmos / Dolby Audio 支持方向
- 逐字歌词 / 增强歌词解析
- 高清封面显示
- 扫描目录管理
- 沉浸封面播放页
- 杜比能力检测页
- 关于页
- 液态玻璃风格 UI

## 当前状态

当前项目仍处于早期开发阶段，可能存在不稳定情况。

## 安装

你可以在 Release 中下载 APK 进行体验。

## 构建

本项目是一个 Android 工程，基于 Kotlin / Jetpack Compose / Media3。
